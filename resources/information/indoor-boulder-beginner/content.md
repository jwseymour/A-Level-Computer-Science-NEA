# Indoor Bouldering Basics

## Level Description
Beginning boulderers are learning:
- Basic movement patterns
- Fall technique and spotting
- Problem reading
- Safety awareness on the wall and pads

## Physical Benchmarks
- Can complete V0-V2 problems
- Basic grip strength for hanging
- Ability to do 1-2 pull-ups
- Core strength for basic movements
- 20-second dead hang

## Key Areas for Improvement
1. Movement Fundamentals
   - Static movement control
   - Basic foot placement
   - Body positioning
   - Weight transfer

2. Safety Skills
   - Proper falling technique
   - Spotting basics
   - Pad placement
   - Landing zone awareness

3. Mental Aspects
   - Height management
   - Basic problem reading
   - Movement visualization
   - Focus development

## Progression Strategies
- Focus on technique over difficulty
- Regular falling practice
- Strength building exercises
- Movement pattern repetition
- Basic conditioning
